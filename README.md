# kfood-top3-agent

K-과자·빙과(HS 1704 · 1806 · 1905 · 2105) 수출 유망국 TOP3 를 명령 한 번으로 낸다. 다만 추천만 내지 않는다. 그 추천을 낸 방법이 과거에도 맞았는지 되감기 시험으로 재고, 후보마다 반론을 붙여 통과한 나라만 카드에 올린다.

롯데 AX 챌린지 2026 예선(롯데웰푸드 과제 「K-푸드 수출 유망국가 발굴」)에 낸 문제해결방안의 프로토타입이다. 되감기 시험의 출발점은 공개 저장소 [kfood-export-backtest](https://github.com/serenwoon/kfood-export-backtest)이고, 같은 원자료로 돌리면 그 저장소와 같은 숫자(15개 추천 중 공식 9 · 크기순 11 · 추세순 10 · 무작위 8.66)가 나온다. 시험이 그것을 확인한다.

## 돌리기

윈도우 PowerShell 에서 한 줄씩 붙인다. 파이썬 3.12, 외부 패키지는 쓰지 않는다.

```powershell
python -m venv "C:\경로\kfood-top3-agent\.venv"
```

```powershell
& "C:\경로\kfood-top3-agent\.venv\Scripts\python.exe" -m pip install -e "C:\경로\kfood-top3-agent"
```

```powershell
& "C:\경로\kfood-top3-agent\.venv\Scripts\python.exe" -m top3 run
```

끝나면 `out\<실행 id>\card.md` 를 연다. 같은 폴더에 `card.json`, `metrics.json`, 되감기 시점마다 무엇을 골랐는지 적은 `log.txt` 가 있다.

처음 실행은 UN Comtrade 와 세계은행에서 원자료 300건 가까이를 받느라 10분 안팎이 걸린다. 받은 응답은 `data\raw\` 에 그대로 남고 다음부터는 다시 받지 않는다.

인터넷이 끊겨 받지 못한 것이 있으면 카드 끝에 이름이 남는다. 같은 명령을 다시 돌리면 빠진 것만 받는다.

| 옵션 | 뜻 |
|---|---|
| `--auto` | 승인을 묻지 않는다. 이때 반론의 보류 제안은 적용하지 않고 「사람 확인을 기다리는 보류 제안」으로 카드에 남긴다 |
| `--offline` | 새로 받지 않고 `data\raw\` 에 있는 것만 쓴다 |
| `--repeat N` | 같은 원자료로 N번 돌려 TOP3 와 반론 목록이 같은 비율을 `metrics.json` 에 적는다 |

## 무엇이 어떻게 도나

다섯 단계다. 수집, 점수, 되감기, 반론, 카드.

점수는 프로그램이 계산한다. 방식은 여섯 가지가 [registry.json](registry.json) 에 등록돼 있다 — 크기순, 추세순, 실측 07 의 공식, 수입 시장 성장, 한국 몫을 뺀 남은 시장 크기, 한국이 파는 세부 품목(HS 6단위) 쪽 수요의 성장. 질문은 둘로 나눴다. 이미 큰 시장에서 더 늘릴 곳, 그리고 그해 수출 상위 3개국을 뺀 「다음 시장」.

되감기는 2016~2018 세 시점으로 방식을 고르고 2019~2020 두 시점으로 확인한다. 정답은 그 뒤 4년 동안 한국 수출이 실제로 늘어난 금액이다. 상식 기준선(크기순·추세순)보다 앞 구간 적중이 둘 이상 많아야 「앞섰다」고 보고, 확인 구간에서 기준선보다 못하면 기준선으로 되돌린다. 앞선 방식이 없으면 기준선으로 TOP3 를 내고 카드에 그렇게 적는다.

반론은 후보를 빼거나 조건을 붙일 뿐 순위를 올리지 못한다.

이번 판의 반론은 통계로 판정하는 규칙 다섯이다. 재수출 거점, 줄어드는 시장, 한국 몫 30% 이상, 비어 있는 시장 자료는 조건이 되고, 시장과 한국 수출이 함께 줄면 보류 제안이 된다. 보류 제안으로 후보를 빼는 것은 사람이 「예」라고 할 때뿐이다.

## LLM 없이 도는 것과 빠지는 것

LLM 키 없이 끝까지 돈다. 빠지는 것은 글을 읽는 반론 — 규제·인증, 물류, 현지 경쟁 제품 같은 것을 기사에서 찾아 인용과 함께 붙이는 일 — 이고, 카드에 「LLM 반론: 건너뜀(키 없음)」으로 남는다.

공급자를 갈아 끼우는 자리와 인용 대조(인용이 그 주소의 원문에 실제로 있는지)는 만들어 두었고 가짜 공급자로 시험한다. OpenAI 나 Anthropic 연결은 다음 판이다.

`sources\urls.txt` 에 주소를 한 줄씩 적거나 `sources\` 에 글 파일을 두면 반론 에이전트가 읽을 자료가 된다. 지금은 LLM 이 없어서 읽기만 하고 쓰이지는 않는다.

## 미리 밝혀 둘 것

등록부는 실측 07(2026-10-29)의 결과를 본 뒤에 썼다. 동점일 때 증가액으로 가르는 규칙도 그 결과를 보고 정했다. 새로 넣은 방식 셋(수입 시장 성장, 남은 시장 크기, 세부 품목 수요)의 되감기 결과는 등록부를 고정한 뒤 처음 계산했다.

숫자는 한국 전체 수출이다. 특정 회사 실적이나 해외 공장에서 파는 물량은 수출 통계에 없다. 수입은 소비와 같지 않고, 금액은 명목 달러다.

이번 추천의 기준 연도는 각국 수입 자료가 대부분 있는 마지막 해인 2024년이고, 2025년 한국 수출은 참고 열로만 보여 준다.

## 시험

```powershell
& "C:\경로\kfood-top3-agent\.venv\Scripts\python.exe" -m pytest "C:\경로\kfood-top3-agent\tests" -q
```

네트워크 없이 돈다. 공개 저장소 숫자를 재현하는 시험은 `data\raw\` 에 실측 07 원자료가 있을 때만 돌고, 없으면 건너뛴다.
